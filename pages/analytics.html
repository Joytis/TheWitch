How to read this page

Window is the slice under study (default: the newest release line, all its patches); vs is the baseline every Δ is measured against (default: the line before). Solo is the default mode because co-op teams carry each other. "Base-game world" drops runs that went through another mod's acts or met another mod's monsters — those change the difficulty underneath the Witch.

Balance target (default 30%, set in the filter bar). The win rate the character is balanced around. Card, archetype and relic verdicts are judged against it: Strong ▲ when the whole 95% interval sits above it, Weak ▼ when it sits below, Leaning strong / Leaning weak when the estimate is more than half an interval away, Near target otherwise. A card's win rate is the window's run win rate plus its taken-vs-passed lift, so if the whole character runs above target, its average card does too. The target is one number for every filter — at A10 nearly everything reads Weak.

Wins vs expected. Who is playing moves win rate far more than any card. Every run gets an expected win probability from a logistic model fitted on all Witch runs on record:

"Wins vs expected" = (wins − expected wins) ÷ runs, in percentage points. Its 95% interval is ±1.96·√Σp(1−p) ÷ runs — the spread you'd see if the slice were exactly as strong as expected. Player skill is the game's own lifetime win rate for that player (every character); the uploaded value already includes the run itself, so that run's result is backed out first.

Taken vs passed (card / Ancient lift). At each reward screen, the runs that took a card are compared with the runs that saw it and passed, each against expectation. Both groups reached the same screen, so the "long runs collect more cards" bias cancels. It still reflects the choice: a card can show a negative lift because the alternatives it was offered beside were better.

Verdict caveats. Too few: under the minimum sample (cards: the "min offers" stepper, with at least a quarter of that taken and passed; archetypes 10 runs; relics 15). With ~100 cards, expect a handful of Strong / Weak verdicts by chance alone — look for ones that persist across releases.

Archetype = mechanic with the most own cards in the final deck (3+), from the curated tags in Docs/card-data/cards.json. Card / relic / encounter detail tables cover the newest 3 release lines; run-level tables cover everything.

Data: nightly export by tools/analytics/export_stats.py from the runs table. No player hashes or per-run rows are published — only summed counts.
