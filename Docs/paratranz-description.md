1. We are Active on the STS Discord: https://discord.com/invite/slaythespire . If you have a question, please feel free to reach out there directly (or on the workshop!). Unless you tell me otherwise on Discord, I will put your ParaTranz / GitHub name in the credits.

2. Descriptions should align as closely as possible with the official descriptions from the base game.

3. The localization text for the base game can be extracted from its .pck file using GDRE; https://github.com/Alchyr/ModTemplate-StS2/wiki/Extracting-Assets-and-Text. its possible to only select and extract the localization folder

4. Certain reappearing base names, such as Strike, Defend, Tackle, or Lick, are used as tags in the game's code. Because of this, whenever such a name appears as part of a longer card name, the established translation of that base name must be preserved within the translated title, not replaced with something different (e.g. in French "Combo Tackle" → "Tacle combo", keeping "Tacle" as the translation of "Tackle"; "Double Lick" → "Double Léchouille", keeping "Léchouille" as the translation of "Lick").
